# Burial

A RedM VORPCore script designed specifically for **Doctors** and **Law Enforcement**. This script allows authorized job roles to interact with specific graves across the map to properly bury deceased locals/NPCs.

---

## 🛠️ Requirements / Dependencies

This script is built exclusively for **VORPCore**. Ensure you have the following installed and running:

* **VORPCore** (Framework)
* **vorp_inputs** (or your server's default interaction prompt/input system)

---

## ✨ Features

* **Job-Restricted:** Restricted specifically to players with designated **Doctor** or **Law** jobs.
* **Grave Interactions:** Contextual interaction prompts that trigger when approaching predefined grave locations.
* **Local Burial Mechanic:** Allows players to perform a burial sequence/animation to clear dead locals.
* **Configurable:** Easy configuration for adding new grave locations, allowed job names, and interaction distances.
